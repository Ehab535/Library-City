# مصروفي

تطبيق أندرويد بيسجّل مصاريفك بالكلام بالعامية المصرية. بيعرف لوحده المبلغ والتصنيف والحساب (كاش، محفظة موبايل، انستاباي) من جملة زي «دفعت 120 أكل من الكاش».
البيانات كلها بتتحفظ على الموبايل بس.

## الجديد في 1.1

- **العمليات المتكررة:** زي الإيجار والمرتب والنت، بتتسجل لوحدها كل شهر. ولو التطبيق فضل مقفول، أول ما تفتحه بيسجّل الشهور اللي فاتت.
- **ميزانية لكل تصنيف:** حد صرف شهري لكل تصنيف، وليه شريط على الداشبورد.
- **مقارنة بالشهر اللي فات:** بيقارن صرفك بنفس الفترة من الشهر اللي قبله، وبيقولك أكتر حاجة صرفت عليها.
- **إخفاء الأرصدة:** زرار العين في كارت الرصيد.
- **تذكير يومي:** إشعار في الساعة اللي تختارها.
- **تواريخ أكتر في الكلام:** «يوم الخميس»، «الجمعة اللي فاتت»، «من يومين»، «من 3 أيام».
- **ملاحظات أنضف:** كلمات زي «قبضت» و«سحبت» مبقتش بتتكتب في ملاحظة العملية.
- **الخطوط جوه التطبيق:** الشكل بقى ثابت حتى من غير نت. قبل كده كانت الخطوط بتتحمل من Google Fonts.
- **أيقونة وشاشة بداية جديدة:** الأيقونة بقت adaptive، وشاشة البداية بقت بشعار التطبيق بدل لوجو Capacitor.
- **آخر العمليات:** الداشبورد بيعرض عمليات الشهر المختار بس.

## التشغيل

```bash
npm ci
npm test                 # اختبارات فهم الكلام
npm run serve            # تجربة في المتصفح على http://localhost:8080
npx cap sync android     # نقل الملفات لمشروع الأندرويد
cd android && ./gradlew assembleDebug
```

الـ APK بيتبني لوحده على GitHub Actions مع كل push بيغيّر حاجة في `masroofy/`. هتلاقيه في صفحة الـ workflow تحت اسم **Masroofy-APK**.

## الملفات

- `www/`: التطبيق نفسه (HTML/CSS/JS من غير build step)
  - `parser.js`: بيحوّل الكلام لعمليات
  - `defaults.js`: التصنيفات والحسابات والكلمات اللي بيتعرف بيها
  - `app.js`: الشاشات والمنطق
- `android/`: مشروع Capacitor
- `test/`: اختبارات الـ parser
